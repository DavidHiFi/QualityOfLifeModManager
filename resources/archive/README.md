# Embedded archive engine

Unmodified 7-Zip 26.04 x64 by Igor Pavlov, released October 5, 2026.
The app embeds `7z.exe`, `7z.dll` and `License.txt` and prepares them in its
per-user cache. Users do not need to install 7-Zip or download an extractor.
ZIP, 7z and RAR use this same engine.

Binary source: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-x64.exe
Corresponding source: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-src.tar.xz
Upstream: https://www.7-zip.org/
